# 工程交付包：版本身份与离线复核

- 日期：2026-10-21。
- 状态：打包/复核工具及迁移隔离验证已通过；当前交付仍为工程开发版。
- 目标：将当前源码与选定的 M3/M4 证据组成可迁移归档，离开原工作区仍可核对身份、审计运行和重算已有指标。

## 范围与取舍

已有 M3 索引指向多个本机 runs，不能单独交付；原 Request 使用绝对路径，M4 本地构建缓存超过数 GB。需要同时保留原证据和可操作的复核入口。

| 方案 | 得失 | 本次选择 |
| --- | --- | --- |
| 只交付源码/Git revision 和索引 | 小，但当前有未提交实现，且没有运行产物，无法复核已有结论 | 不采用 |
| 整体归档全部 runs | 引用最多，但混入大量重复尝试和数 GB 构建缓存，也没有区分交付边界 | 不采用 |
| 重写原报告中的绝对路径 | 导航直接，却破坏原字节摘要、检查点和签署身份 | 不采用 |
| 显式材料清单、逐文件身份、保留原文、生成新复核请求 | 需维护选定范围，但可验证迁移且不重写历史 | 采用；构建缓存排除，实际迁移审计检验是否漏材料 |

打包属于交付工具，不向 Harness Runtime 加新框架或业务命令。使用 Python 3 标准库处理复制/摘要/tar，Go 工具链从导出的源码离线构建 harness 和既有轮次汇总器；不新增第三方依赖。代价是创建包需要 Git、Go、Python，完整执行复核目前需要匹配所附二进制的平台；其他平台可先核对完整性、从源码自行构建，不将交叉编译称为实机验收。

## 交付契约

显式清单选择原真实三仓 Campaign、独立参考、两份用户复核和助手补充校准，以及 M4 精确预算窗口、六个受控恢复场景和真实连接故障链。历史日志作历史证据，不重跑供应商、Docker 或候选；归档不承诺覆盖全部历史实验，也不称正式 M5 样本集。

源码从 Git 列出的已跟踪及未忽略的新文件中按 cmd/internal/scenarios/scripts/docs 等明确根选择，排除 .git、凭证及个人目录；不读取 .env。清单固定真实工作区文件摘要，而非只有 HEAD。构建从导出副本进行；保留父 revision、工作区身份、构建参数/工具链、实际二进制摘要。逐文件清单不包含自身，tar 另附 SHA-256；这是完整性和身份记录，不是第三方签名。

原运行目录结构放在 source/runs，既有报告、候选、参考、签署与原 Request 的字节不改。新复核 Request 只对自己携带的路径做映射，所有输入须落在解包目录和已登记文件内。调用现有 audit/round，分别核对运行状态和原轮次 counts/metrics/cost/targets；原表中的 null、两份人员与助手校准分列规则保持。

验证输出必须是包外的全新目录，不能覆盖交付；缺文件、内容/模式漂移、额外文件、链接或路径越界先拒绝，再执行二进制。不因 SHA 自洽认证归档作者或外部来源可信。原审核报告中的六个断链作为旧交付缺陷保留，新包入口只保证选定材料可到达。

## 实施与验收计划

1. 实现显式清单、复制/身份/打包和离线核对工具，补路径、链接、篡改/缺失/额外文件及请求映射测试。
2. 创建试包，从新目录解包，审计原真实批次与选定恢复记录，重算三份原汇总并比较。
3. 在不能读取原工作区、不能联网的独立进程中复核，固定最终版本和 tar 摘要；检查输入原文未变、凭证未纳入。

正式冻结门、实际留出与人员口径缺口仍在；本包是当前工程开发版的交付，不能据此宣布 M3/M4 总体验收或 M5 完成。Git 保持未暂存、未提交，运行产物放在 runs。

## 实际实现与验证

新增 `scripts/package_delivery.py`、边界测试及版本化材料清单。创建时独占输出，导出当前源码、复制显式材料、从副本以 -trimpath/-buildvcs=false 构建两个二进制，固定文件字节/模式、源码聚合摘要和父 revision；tar 单独保存外部 SHA-256。复核器先验证全部成员，再使用包内二进制执行固定 audit 和 summarize，结果写包外新目录，最后重新核对包未变。生产 Go 代码和原始运行材料没有修改。

清单选定 25 个材料根/文件，包含原三仓批次与独立参考、两份实际用户记录、助手补充、恢复事务证据、精确预算窗口、六个完整恢复场景及连接故障链；执行入口为 8 个 Campaign 审计和 3 份轮次重算。预算/故障数据仍属于受控机制，不将它们加入真实效果分母。

试包约 295 MB 未压缩、115 MB 压缩，含约 1.2 万成员；大头为原始依赖与证据，数 GB 构建缓存已排除。平台是 darwin/arm64、Go 1.26.5；最终精确成员和字节以交付 manifest 为准。它提供记录核对及计数重算，不承诺在无 Docker/原模型条件下重新执行候选或生成相同补丁。
