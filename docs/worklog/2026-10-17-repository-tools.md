## 本步交付

`internal/repotools.Executor` 实现 `agent.ToolExecutor`，通过 `Specs()` 提供当前可用的工具参数说明。循环无需了解文件系统、Go 命令或具体迁移场景。

| 工具 | 参数 | 行为 |
| --- | --- | --- |
| `list_files` | `root`、`path` | 列出目录的直接子项，目录以 `/` 结尾 |
| `read_file` | `root`、`path`、可选 `start_line` / `end_line` | 读取文本，行号从 1 开始，范围包含两端 |
| `search` | `root`、`path`、`text` | 递归搜索单行字面文本，输出相对路径、行号和匹配行 |
| `replace_text` | `path`、`old`、`new` | 仅替换候选仓库已有文件中恰好出现一次的原文本 |
| `go_check` | `kind`：`build` 或 `test` | 在候选目录执行固定的 Go 构建或测试，需宿主显式启用 |

`root` 是宿主配置的别名，如 `workspace`、`rpcx-v1`、`rpcx-v2`，不是任意磁盘路径。模型不能通过参数新增可见目录。写工具只接收候选目录的相对路径，不接收根目录参数。

首版只支持已有 UTF-8 文本文件的精确替换，没有创建、删除、重命名文件或任意 shell 工具。当前 T1/T2 迁移所需的源码、测试和 `go.mod` 都已存在，可通过连续替换完成适配。

## 与循环连接

宿主先在运行目录准备候选和 SDK 副本，以及独立缓存目录，再配置执行器。下面的路径变量由宿主提供，`model` 后续接真实模型适配器：

```go
executor, err := repotools.New(repotools.Config{
    Workspace: candidateDir,
    ReadOnlyRoots: map[string]string{
        "rpcx-v1": sdkV1Dir,
        "rpcx-v2": sdkV2Dir,
    },
    ProtectedPaths: []string{"internal/pb"},
    LocalGo: &repotools.LocalGoConfig{
        CacheDir: cacheDir,
    },
})
if err != nil {
    return err
}
loop := agent.Loop{
    Model: model,
    Executor: executor,
    Tools: executor.Specs(),
    Limits: agent.Limits{MaxModelCalls: 20, MaxToolCalls: 40},
}
result, err := loop.Run(ctx, initialMessages)
```

不设置 `LocalGo` 时，执行器只公布四个文件工具，并拒绝直接请求 `go_check`。规范文本由宿主提供给模型；参考补丁、cases、oracle 不应被配置成可见目录，也不应放入候选目录。

## 文件边界与错误反馈

- 可写候选目录经规范化后不得与只读目录重叠，只读目录之间允许重叠；缓存目录不得与任何可见目录重叠。配置会复制进执行器，模型不能改变它。
- 相对路径不得包含绝对路径、`..`、反斜杠或 `.git`。检查每层路径，拒绝符号链接和特殊文件；搜索不跟随符号链接，不读取 Git 元数据。
- SDK 可读取但不能通过替换工具写入；受保护路径按完整路径或目录前缀匹配。保护规则由宿主提供，当前场景配置 `internal/pb`。
- 精确替换拒绝空原文、无匹配和多匹配，包括重叠匹配；允许以空新文本删除唯一片段。同目录临时文件写完后重命名，保留普通权限位，避免部分写入及硬链接共享内容被改动。
- 参数错误、路径拒绝、文件读取失败或匹配失败作为 `ToolResult.IsError` 反馈，模型可修正。取消通过 Go 错误终止循环。

单个文本文件上限为 1 MiB；一次目录列举或搜索最多处理 10,000 个路径。默认输出上限为 16 KiB，可配置为 256 字节至 1 MiB，截断时保留 `[output truncated]` 标记和完整 UTF-8 字符。读取大文本时可缩小行范围；搜索跳过不可读、过大、非文本或特殊文件时会显示数量，达到搜索上限也会提示。代码注释采用中文，工具描述、错误和运行状态采用英文；工具名称由具名常量统一维护，协议值保持不变。

这些检查适用于独占、可信的工作目录，不防御外部进程并发替换目录、硬链接读取越界等恶意文件系统攻击。

## 本地 Go 执行的范围

固定命令为 `go build ./...` 或 `go test -count=1 -timeout=<配置值> ./...`。没有模型可控的命令、额外参数或工作目录，默认墙钟超时为两分钟。

执行环境关闭模块代理、校验服务、工作区、自动工具链下载和 CGO，固定只读模块模式，使用独立缓存与临时目录，不继承宿主凭证变量和自定义 Go 参数。这里的“离线”约束针对 Go 依赖解析，不能阻止测试代码自行访问网络。

macOS 和 Linux 使用独立进程组，取消时终止组内进程；命令结束后也尝试回收留在组内的后代。输出持续排空但只保留有限前缀。普通非零退出反馈给模型；启动失败、取消、超时和回收异常终止循环。

**本地执行器不提供进程沙箱。** 仓库测试可执行任意代码，包括绕过文件工具访问宿主、修改 SDK 或受保护文件；主动脱离进程组的后代也不在回收保证内。因此这里只启用可信夹具测试，不能将这些路径规则宣称为真实模型运行时的隔离保证。接入真实模型前，需要明确采用隔离执行后端或受控运行环境，并由独立门禁再次检查候选与保护路径。
