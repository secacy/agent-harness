## 实施前的取舍

### 预算选择

复用既有单任务限制：40 次模型准入 / 80 次工具调用 / 250 万 Token / 10 分钟。既有三仓实验不证明这些数值最优，但当前没有证据支持对新任务单独放宽、或对旧任务收紧；统一限制使本轮任务间的差异更容易解释。

| 方案 | 对四任务的实际影响 | 决定 |
| --- | --- | --- |
| 全批继续 750 万、每任务 250 万 | 总批准额度较低，任务可能因别人先占用共享池而停止；结果混入紧预算竞争 | 本轮不选，若要测共享紧预算另发协议 |
| 全批 1000 万、每任务 250 万 | 总上限增加，但等于四任务上限之和，不额外压缩任一任务自己的额度 | 采用；调用上限同理为 160=4×40，不自动追加 |

历史能力材料中 C=1,048,576，O=4,096，保守 Q=C+O=1,052,672；本轮据此固定期望身份，不声称重新认证当前服务。每任务可预留一次，全批可同时预留两次；次数上限不是保证次数，未知请求占用整笔 Q。1000 万是 Token 上限，不是金额账单上限。外部停止定为 40 分钟加最多 60 秒收尾，比两组 10 分钟 Run 的排程留出控制/初始化余量；这不是实测吞吐保证，单任务仍包含准备和门禁。

### 能力材料和计划绑定

旧开发协议只比较所选模型的预算相关字段；schema 2 已有完整计划摘要，连 Models 响应原文摘要和 Docker engine 都绑定。两个选择是修改该契约以允许无关能力变化，或者接受现有保守拒绝。当前目标是执行固定实现，选后者，不为了这次准备新增能力归一化和另一轮协议机制。

沿用 2026-10-20 已授权查询的原文作为**期望材料**，正式启动仍查询一次当前服务并使用实际 Profile。只有实际设置与本版匹配才接纳任务；响应字节变化也会零生成停止，保留新能力和诊断，不重试、不自动改摘要。若需接受变化，另发版本并重新授权。这避免为准备阶段重复读取密钥，也明确接受了一次 GET 后整轮停止的可能性。

### 复核和归档

采用已委托的助手候选复核，实际预定身份统一为 `codex:/root`。该助手兼任协议准备和运行协调，与各 Run 的 DeepSeek 生成对话分开，但不是独立人员/盲审。其既有知识、GHCLI 主流程此前只读元数据、接入作者已见控制等关系写入协议和 reviewers.json；复核结论与活动时间未发生就不填写。

实现身份只覆盖 cmd/internal/scenarios/scripts、go.mod/go.sum，协议文档另行固定。这样实现归档不引用包含自身摘要的协议文件，避免递归身份；762 份文件的完整列表纳入协议。复用现有导出/摘要方式，用标准库 tar/gzip 保存实际源码、离线输入/依赖和两个二进制，不把旧工程 v0.1.1 包冒充本轮实现，也不加入缓存、凭证或旧运行。当前执行配置绑定本机路径/引擎，搬到别处运行须先另发协议，不静默重写身份。

## 实际准备

1. 调用既有 `TargetFrom*`、`ValidateTarget` 和 `PublishedIdentity` 取得公开元数据，实际校验 13 个业务/依赖目录树、四份规范摘要和四种当前参考身份。主流程不输出或打开新应用业务、规范正文、测试/控制答案；可信工具只做摘要计算和必要的材料认证。
2. 只读核对本机 Go 1.26.5 / darwin arm64、现存固定镜像 linux/arm64、orbstack context 与 engine 身份；没有拉取镜像或创建容器。实际环境写入 environment.json。
3. 导出源码快照，从副本使用 `-trimpath -buildvcs=false` 和禁网模块设置构建 harness、summarize。冻结实际文件摘要、源码集合、二进制及归档；不能只用父 Git revision 代表内容。
4. 发布 batch、schema 2 Enrollment、dataset、reviewers、四份协议材料、历史能力原文/解析及 expected-plan。后者用于核对期望设置，明确不是实际 Campaign；实际查询时间与落盘 Plan 原文身份保留到运行时。freeze.json 对本目录其余文件原文取摘要，不包含自身。
5. 用实际二进制执行 `--check`，并调用现有 `Enrollment.Bind` / `ReadProtocolMaterials` 对期望 Plan 检查完整关联。之后把实现 tar 解包到全新临时目录，从该源码重建两工具，比较二进制摘要并重跑离线入口。

本步没有修改生产 Go、测试、门禁或冻结数据，没有发起真实能力 GET/生成 POST，也没有读取 `.env`。前一实现单元的竞态回归仍属前一单元，本轮不重复计作新业务验收。
