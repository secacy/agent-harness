## 问题与适用范围

在固定实现、任务和预算下，衡量公共 rpcx SDK 不兼容升级的自动交付、错误放行、未知结果与成本。机制故障试验、已见开发校准和未见样本效果分别报告，不合并分母；不推断任意 SDK、仓库或供应商上的生产概率。

已有 [l2-dev-eval-v0.1.0](l2-dev-eval-v0.1.0/README.md)是完成的开发实验，不转为 M5。Goddd、Translation、Workouts 均已参与调优，只能作开发回归。留出名额不是样本；实际独立准备者、来源/同源组、保管和访问记录尚缺。本协议草案不新增或查阅留出输入与答案。

## 拟采用的实验规则

正式发布时须把下表的待定项换成真实清单和数值。发布后有实质变更即新版本，原失败和偏离记录保留；不能在看到结果后换样本、调预算或挑最好 Run。

| 项目 | 拟定规则 / 冻结所需材料 |
| --- | --- |
| L1 机制回归 | 固定任务 manifest 和 expected、规范条款、实现身份；逐 case 检查 verdict 与证据引用。输出构造集计数，不用其人为错误比例估计真实放行风险 |
| L2 开发回归 | 固定三个已见来源的实际数据版本、Profile、全部必需配置及独立参考；与留出分表，不以旧校准替代本次运行 |
| L2 正式留出 | 沿用 M3 同源分组原则；准备者单独保管。实际来源/版本/摘要、样本数量和基线检查流程待齐备，未齐备不得冻结 |
| 次数与候选选择 | 拟每 Target 一次正式生成尝试、一次候选；重复次数为 1，不宣称统计稳定性。未启动、基线红、超时、预算耗尽、非法回复、设施失败均在已纳入 N 内，列原因 |
| 重试与恢复 | 正式效果轮不自动重试、不人工修复、不更换原候选；M4 恢复单列确定性故障实验。正式生成中断后保留状态/占用和失败，不拿恢复后最好 Run 顶替；如需评估多次尝试，另起协议并先实现对应多 Run 汇总 |
| Agent 与门禁 | 固定提示/工具/预算提示、模型适配、门禁和 Profile；每 Run 独立对话。Agent 仅见本任务必要输入；oracle、expected、参考、其他任务和账本不进入可见根；门禁不读取 oracle |
| 模型与预算 | provider/endpoint/model、模式、max_tokens、C/O 来源、单请求 Q、两级调用/Token 上限、工具/Run/整轮时限和 N/K 全部待实际冻结；不沿用旧单次授权、不以 Token 冒充金额账单上限 |
| 环境 | 完整源码与依赖、二进制、Go/OS/架构、镜像 digest、Docker context/engine、资源限额、网络/挂载/缓存规则及原生命令；不能只固定未包含工作区修改的 HEAD |
| 纳入与发布 | 生成前绑定任务顺序/输入/规范/Profile/参考/工具及协议摘要；保存实际 Plan 后、接纳前发布动态纳入材料。能力或材料不符合冻结值时零生成停止，不临时放宽 |

目前 [v2 协议契约](../../scenarios/rpcx/l2/round/README.md#v2-协议契约)已接入 formal_evaluation：生成前绑定计划设置、实际后端、四份材料与预定复核人，离线重查发布副本；开发夹具及本机模拟服务验证机制，不计本轮正式结果。当前仍只支持三个既有 L2 Profile 和 development 分区；未接入的 heldout 明确拒绝。实际留出及认证、完整材料与角色尚需落实，不能靠新字符串或合成材料通过 M5 验收。本草案不是 CLI 配置格式，不提供不可运行的命令。

## 独立参考与复核

对所有可认证候选运行独立参考，包括 Rejected 和 NeedsAttention；无法取得完整候选时保留不可评原因。固定参考数据/工具、执行参数、必需配置、事件和计时容差，不因新候选失败放宽。

自动结果为 pass / fail / inconclusive：候选确定违反规范才能记语义 fail；参考编译不适配、设施失败、缺事件或不足证据保持未知。自动 pass 后仍须按冻结人员安排实际复核 test_preservation、change_coverage、delivery_evidence，记录身份、带时区时间、材料定位、理由及与开发调优的关系。助手可辅助，不能代替实际人签署或声称盲审；缺复核保留未知，不补写 pass。

迁移/测试错误和交付依据错误分别计数，同一候选在总错误数只计一次。完整参考 pass 也不能把原 NeedsAttention 改为 ReadyForReview。若正式结果被用于调优，该样本此后转为开发用途，不能在新轮继续声称未见。

## 计数与指标

每个 split 单独统计。N 是生成前纳入 Target 数，R 是实际 Run 数，Q 是获得原质量判定数，A 是 ReadyForReview 数，H 是 NeedsAttention 数。没有生成候选不从 N 删除；配置在接纳前非法时保留拒绝记录，不虚构一轮有效比例。Translation 多构建配置仍是同一个 Target。

| 指标 | 定义与未知处理 |
| --- | --- |
| 有效自动成功 | S 为原 Run Completed、ReadyForReview 且完整独立参考 pass 的数量，报告 S/N。放行但参考未知的潜在成功数 u_s 单列，必要时报告 [S/N,(S+u_s)/N]，不把下界当完整成功率 |
| 错误放行 | k 为放行候选中完整参考确认错误数，u 为放行后未知数；A=0 无定义，不能填 0%。A>0 且 u=0 报 k/A，否则只报 k/u/A 和 [k/A,(k+u)/A]；该范围不是统计置信区间 |
| 人工确认 | 同时报 H/N 和 H/Q；Q=0 时后者无定义。另列执行失败、未启动及无判定，不将此比例称为人工耗时 |
| 成本 | Campaign 总账只计一次；分列各 Target/Run、准入/拒绝、Loop 尝试/工具调用、实际已知输入/输出、未知保守占用和在途预留、墙钟/验证耗时。未知不填零；金额和实际人工活动时间无证据时保持未知 |
| 故障与质量分布 | 统计配置/基线、API/协议、预算、工具、设施、中断、发布故障；执行 Failed 与质量 Rejected/NeedsAttention 分列。构造故障不进入正常效果分母 |

身份或摘要冲突使该轮无效，保留诊断与成本；不得发布有效效果比例。参考未完成使相关结果未知，不把它混同整轮身份无效。小样本只说明观察到的个案，零错误不等于普遍无错误。

## 冻结、执行和复核交付

正式冻结需同时具备：不可变协议版本；实际样本/split 与保管记录；逐任务输入/规范/Profile/参考/工具；完整实现/二进制/环境；模型能力与所有预算/时限数值；一次尝试和复核规则；可用且验证过的正式纳入/汇总链路。逐文件摘要清单不包含自身，不能填占位摘要或只附名额。当前均以[冻结门表](../worklog/2026-10-21-m4-closeout-review.md#4-正式评测的冻结门)记录，不标 frozen。

材料固定并获该次外发/开销授权后才运行生成；先记录协议与实际 Plan 绑定，再接纳任务。中断、协议偏离和所有失败单独保存；严重身份/预算偏离停止，不事后重写原记录。M4 工程缺口未闭环前，不宣布 M5 正式启动。

交付包含原始计划/账本/所有 Run、补丁/候选/规范/日志、门禁、参考和复核、汇总原始计数及失败分布、源码/环境重建说明与逐文件摘要。密钥不入包。由他人按归档重算指标、复验保存候选和审计记录，不承诺重新请求模型得到相同补丁。仅交付指向本机 runs 的索引不算完整归档。

若独立准备条件始终不具备，可交付已见开发集报告及工程证据；那是带局限的开发版，不能以更名代替原 M3/M5 的留出与正式效果验收。
