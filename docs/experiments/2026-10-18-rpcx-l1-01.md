## 预设条件与复现

冻结 22 份 L1 数据材料后运行，旧 T3 的 34 份材料不变。每例门禁与参考独立并行，case 之间串行；只读候选与 SDK，测试文本、输出目录和判定逻辑分离。参考剥离候选测试，使用两个旧独立参考模板及一个新增请求变体，不复用运行时探针。

```sh
env GOPROXY=off GOSUMDB=off GOWORK=off GOTOOLCHAIN=local GOFLAGS=-mod=readonly GOCACHE="$PWD/runs/go-cache" go run ./scenarios/rpcx/l1/cmd/verify -trusted-local
```

本地为 Go 1.26.5、darwin/arm64、cgo=0、默认 tag，复用离线编译缓存，只执行受控夹具。Docker 使用既有固定 Go 1.26.5 Linux arm64 镜像，每容器 2 CPU/2 GiB/128 PID、禁网、只读挂载，无隐式拉取或宿主回退。Docker 对照命令：

```sh
env GOPROXY=off GOSUMDB=off GOWORK=off GOTOOLCHAIN=local GOFLAGS=-mod=readonly GOCACHE="$PWD/runs/go-cache" go run ./scenarios/rpcx/l1/cmd/verify -development -cases=correct-timeout,wrong-duration,unprobed-branch
```

不使用模型、模型凭证或网络。只在参考快检查通过后运行真实到期，不从 gate verdict 或 expected 选择慢检查。

## 解释边界

这些计数来自已知构造任务，仅说明声明机制与支持范围符合预期，不能推导真实仓库自动成功率或未见样本错误放行率。行为 oracle 不认证原断言保留、SDK 不可改、所有构建配置或任意生产代码无恶意。默认参考通过和缺口并存时仍需保留人工关注；没有把所有样例都归入 NeedsAttention。
