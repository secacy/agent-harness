## 实验与固定条件

Goddd、Translation、Workouts、GHCLI 四个已见切片，A/B/C 每任务各三次，共 36 次独立生成。A 为普通仓库工具与最小完整任务提示；B/C 使用同一完整生成配置，Translation/Workouts 开启现有两次按需诊断；A/B 正常提交并完整交付即放行，C 另需现有独立门禁 `ReadyForReview`。三组都使用同一 `final-response-v1`、保护路径和只读输入。最终门禁不返回模型继续修复。

主实验串行运行，按重复、任务顺序轮换组别：第一次 Goddd A/B/C、Translation B/C/A、Workouts C/A/B、GHCLI A/B/C；下一次整体轮转一位。顺序在 `Schedule` 中完整固定。每次独立对话、目录、缓存、模型实例、账本账户及 Run 身份；不共享候选，不声称配对种子可重复供应商采样。每项只执行一次，不在看到结果后追加、替换、删除或人工修补。

## 用量与费用方案

冻结的 [价格依据](price-basis.json) 使用官方高峰价作为统一保守估算：每百万 USD 0.30 未缓存输入、0.006 缓存输入、1.20 输出。供应商低峰优惠不用于宣称节省；表中金额是统一单价估算，不能称为实际扣费或账单。[官方价格表](https://api-docs.deepseek.com/quick_start/pricing/)说明低峰费率和调整权，正式运行前需再次确认。

90,000,000 token 全按最高单价计算的保守金额界限为 **USD 108**；这是一份需明确授权的最坏额度方案，不是预测会花费 108 美元。现有账本按每次完整上下文上界加输出上限前置预留，因此实际可用额度会小于名义余量；耗尽时正常停止，不放松上界以完成样本。

五个 P0 历史 Run 共 137 次准入、1,999,920 输入与 26,956 输出；缓存命中 1,910,272、未命中 89,648。用上述高峰价重算约 USD 0.0707，按 36/5 等比例仅约 USD 0.509。此缩放未考虑 A 提示、独立随机生成及失败差异，**不是可靠预测、费用承诺或本轮效果证据**。保守上限与历史缩放同时保留，资源授权不能用后者代替前者。

硬限制由去重持久化 token/调用账本执行；金额依据冻结单价换算，供应商改价或供应商账单差异不由本地 ledger 控制。未知调用继续保守占用；没有缓存拆分时金额未知，不能视为免费。任何价格、模型或总额度变化需另行明确授权。

放行决定在参考评测之前保存。所有固定候选都进入同一独立参考，包括拒绝、证明不足、执行失败及未正常提交的残留；残留即使正确也不能补计自动交付成功。候选正确性采用自动参考加测试保留/变更覆盖复核，交付说明准确性单列。未填复核默认未知，不能用原门禁或 Agent 自述填补。

局部候选、模型或参考执行失败保留原项并继续其他预定项；共享输入/账本不可信、资源回收未知或父取消时停止后续调度，保留未启动行。索引停在 starting 的完整终态可只读认证，不重新生成；不完整收据只保留未知和占用。损坏已确认终态不能被当作通过。

每组分母固定 12、每任务每组固定 3。报告自动成功率、错误放行率、误拒率及其分子分母；未知放行给可能范围、零分母 N/A；候选正确率、说明准确性、阻挡原因分别列出。用量和调用去重，列 token、金额估算、模型/工具调用、step、完整尝试耗时的观测数、缺失数、均值及范围；准备/生成/门禁/收尾阶段原值、独立参考和人工活动时间另存证据。

结果只代表四个已见切片的本轮小样本，不证明未见仓库泛化。B/C 独立生成差异不能解释为相同候选上的纯门禁因果效果。不要求任何组获胜；负收益、无收益与未知均可以形成诚实结论，不能通过事后调参改写本轮。
