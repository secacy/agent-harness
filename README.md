# Multi-Repo Coding Agent Harness

基于 Go 设计实现的多仓库 Coding Agent 运行与验证框架，统一管理 Agent 的批量执行、资源预算、运行状态与验证交付。

当前以公共 RPC SDK 不兼容升级的跨仓库迁移为应用与评测场景。
